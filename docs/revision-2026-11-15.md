# Проверка замечаний от 2026-11-14

Разобраны все 16 замечаний: 11 исправлены, 5 отклонены после проверки кода.
Открытых идей на момент ревизии не было.

## Исправления

- `--doctor` в Bash узнаёт уже выбранный локальный ffmpeg.exe, даже если
  `command -v` его не возвращает. Поведение соответствует PowerShell.
- Генератор значков освобождает кисти, перья, графические контексты и контуры.
  Рисунок и размеры значков сохранены.
- `dual_track` на всех трёх платформах поддерживает видео без исходного звука:
  `0:a?`, индекс перевода 0, кодек и метаданные адресованы добавленной дорожке.
  Успешный пустой ответ ffprobe отличается от сбоя определения дорожек.
- Параметры даты и задержек batch-загрузки Bash читаются один раз до цикла каналов.
- Сбой записи manifest виден как FAIL и запрещает удаление прошлых выходов
  на всех платформах. Проверены отказ записи временного файла и сохранность
  прежнего manifest и старой части, которую успешный прогон должен удалить.
- CMD проверяет целую часть скорости до умножения на 1000. Контрпример:
  `4294968.0` раньше превращался в 704 milli из-за переполнения 32-битного числа.
- CMD выводит список конфликтов напрямую из файла, сохраняя `!` в диагностике.
- Незакрытая ведущая кавычка сохраняет весь текст значения, включая ` #`:
  Bash, CMD, PowerShell CLI и GUI дают одинаковый результат.
- `human_size` в Bash принимает пустой или повреждённый размер как ноль.
- Селектор MP3-перевода PowerShell работает также без функции вывода GUI.
- Оба удалённых клиента проверяют `REMOTE_RETRY_SECONDS`: неверный ввод даёт
  предупреждение и 3 секунды, большой — максимум 60. Явный ноль сохранён для
  запуска без задержки; рост паузы ограничен до умножения и не переполняется.

Полный прогон дополнительно воспроизвёл ошибку CMD в сопоставлении путей: `findstr`
разбирает обратные слеши даже в буквальном режиме и пропускал конфликтующие входы.
Теперь сравнение буквальное (`/l /i /x`), а слеши шаблона удваиваются;
существующий сквозной тест покрывает случай.

Проверка отказа записи CMD также воспроизвела особенность перенаправления в каталог:
код возврата мог остаться успешным, а `move` заменял manifest каталогом. Теперь
каталоги отвергаются до перемещения, наличие финальной записи проверяется явно.
В тестовом фреймворке явные шаблоны `/tmp/...` подчинены `TMPDIR`, чтобы временные
артефакты и Windows-пути не расходились при соседних прогонах Git Bash.
Недоступный каталог временных файлов теперь немедленно завершает тест с явным
провалом: отсутствие файла счётчиков не может превратиться в успешные «0 тестов».
Негативный тест сканера задаёт границу поиска Git: временный каталог внутри
проекта должен моделировать отсутствие репозитория, не подхватывая родительский.

## Отклонённые замечания

- ASR dry-run: оценка последней части сверху намеренная, некорректный план
  отсечён проверкой длительности.
- ASR speakers: числа в шапке и машинной сводке совпадают; пробел после запятой
  относится к оформлению. Значения не могут содержать служебные маркеры парсера.
- GPU-фильтры PowerShell: порядок hwdownload/format/CPU-фильтров корректен;
  setpts допускает аппаратные кадры.
- Длина комментария CMD: двоичный поиск считает последний индекс, а не длину.
  С исходным значением 2 получается ровно длина разделителя и хвоста;
  предложенное изменение на 1 было бы регрессией.
- Сводка остановленного загрузчика: отдельная ветка уже выводит «Остановлено»
  и число загруженных элементов без общего размера динамической очереди.

Причины и исходные формулировки также сохранены в локальном архиве замечаний.
Регрессионные проверки добавлены в существующие тестовые файлы; копий
production-функций в тестах нет. Правила очистки manifest и чтения конфига
уточнены в [constraints.md](constraints.md).

Среда локальной проверки: Git Bash и Windows PowerShell 5.1. Установленный
антивирус — Windows Defender; Kaspersky в этом окружении отсутствует.
Выполнен полный набор тестов с повторным запуском исправленных наборов.
Единственный платформенный пропуск — имя файла с переводом строки на NTFS.
Оба собранных EXE создали окна приложений с ожидаемыми заголовками.
