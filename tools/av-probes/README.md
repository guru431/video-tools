# tools/av-probes/ — временные пробы для поиска ложного срабатывания антивируса

Между `Downloading_from_YouTube_v16.ps1` (антивирус пропускает) и `v17` (блокирует)
отличий всего четыре. Каждая проба здесь воспроизводит РОВНО ОДНО из них в отрыве от
остального кода.

## Как пользоваться

На машине, где воспроизводится блокировка, запустить каждый файл **правым кликом →
«Выполнить с помощью PowerShell»** (именно этим способом, он воспроизводит проблему).

- проба открыла окно консоли и написала `ПРОБА N: OK` → эта конструкция вердикта не
  вызывает;
- проба заблокирована антивирусом → причина найдена.

Результат — какие пробы прошли, какие нет.

## Что в пробах

| Файл | Что проверяет |
|---|---|
| `p1_manifest.ps1` | создание пустого файла в `%TEMP%` со случайным именем через .NET-API |
| `p2_config.ps1`   | разбор `ini` в хеш-таблицу по правилу «первое вхождение выигрывает» |
| `p3_archive.ps1`  | подсчёт непустых строк файла через `Get-Content` + `Where-Object` |
| `p4_title.ps1`    | строки заголовка окна, изменившиеся с `v16` на `v17` |

Ничего вредного пробы не делают: создают и тут же удаляют временный файл, разбирают
строку в памяти, печатают результат. Каталог удаляется, как только причина найдена.
