# tools/av-rollback/ — откат изменений v16 → v17 по одному

Временный набор для поиска причины блокировки антивирусом. Удаляется, как только
причина найдена.

## Зачем именно так

`Downloading_from_YouTube_v16.ps1` антивирус пропускает, `v17` — блокирует. Отличий
между ними всего пять (плюс комментарии), и каждое по отдельности, вынесенное в
крошечную пробу, вердикта не вызывает. Значит порог набирается **суммой** факторов, и
искать надо не «ту самую строку», а какое снятие опускает сумму ниже порога.

Здесь лежит полный `v17`, в котором откачено ровно одно изменение — по файлу на каждое.

## Как запускать

Каждый файл — **правым кликом → «Выполнить с помощью PowerShell»** (именно так
воспроизводится проблема; `powershell -File` идёт другим путём и не показателен).

- открылась консоль с зелёной надписью `ЗАПУСТИЛОСЬ: …` → антивирус пропустил;
- вылезло окно антивируса / ошибка про malicious content → заблокирован.

GUI не строится: в вариантах подменён тестовый guard, скрипт печатает строку и выходит.
Весь остальной текст файла при этом остаётся нетронутым — антивирус видит его целиком,
как при обычном запуске.

## Порядок и что означает результат

**Сначала два контроля** — они проверяют, что эксперимент вообще корректен:

| Файл | Ожидание | Если не так |
|---|---|---|
| `r0_control.ps1` | **блокируется** (это текущий v17) | подмена guard сама влияет на вердикт → набор непригоден, скажите |
| `r6_all.ps1` | **работает** (это точный v16) | дело не в отличиях v16→v17 вовсе — искать надо в другом месте |

**Затем откаты** — в любом порядке:

| Файл | Что откачено |
|---|---|
| `r1_config.ps1`   | разбор `config.ini`: обратно на «побеждает последнее вхождение ключа» |
| `r2_manifest.ps1` | создание манифеста: обратно на `Set-Content` |
| `r3_archive.ps1`  | проверка «манифест пуст»: обратно на сравнение длины файла |
| `r4_titles.ps1`   | заголовки окна: обратно на `v16` |
| `r5_comments.ps1` | убраны все комментарии, добавленные в v17 (код при этом как в v17) |

Нужен список: какие запустились, какие нет. Если запустился ровно один — снятие именно
этого фактора опускает сумму ниже порога. Если несколько — порог близко, и убирать
придётся не одно. Если ни один, а `r6` при этом работает — значит вклад дают комментарии
и заголовки вместе с кодом, тогда сузим следующим заходом.
